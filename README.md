# # 📊 Анализ оценок учеников с использованием Pandas
main.py
Небольшой проект на Python, демонстрирующий основы анализа табличных данных с помощью библиотеки `pandas`. 
Скрипт моделирует таблицу с оценками 10 учеников по 5 предметам и выполняет базовые статистические расчёты.

## 📚 Что делает скрипт

1. Создаёт `DataFrame` с оценками учеников по предметам:  
   - Математика  
   - Литература  
   - Физика  
   - Химия  
   - История

2. Выполняет анализ:
   - Вывод первых строк таблицы
   - Средняя и медианная оценки по каждому предмету
   - Квартиль Q1 и Q3 по математике
   - Расчёт IQR (межквартильного размаха) по математике
   - Стандартное отклонение по предметам

## 🛠 Требования

- Python 3.7+
- pandas
